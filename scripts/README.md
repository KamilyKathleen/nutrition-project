# 🛠️ Scripts do Projeto

## Estrutura de Pastas

### `/scripts/debug/`
Scripts de debug e testes (não vão para produção):
- `debug-auth.js` - Debug de autenticação
- `test-auth-console.js` - Testes de autenticação no console
- `debug-joao.js` - Scripts de debug específicos

### `/scripts/database/`
Scripts relacionados ao banco de dados:
- `cleanup-db.js` - Limpeza do banco de dados

### `/scripts/utilities/`
Utilitários diversos:
- `checkDietPlan.js` - Verificar planos alimentares
- `listPatientsAndPlans.js` - Listar pacientes e planos
- `fix-imports.sh` - Corrigir imports
- `test-results-*.json` - Resultados de testes

## ⚠️ Importante
Os scripts de debug não são commitados no Git e não vão para produção.
